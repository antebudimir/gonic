# UX

## Theming

- The admin UI is dark-only. Colours come from `server/ctrladmin/adminui/tailwind.config.js` and the source `server/ctrladmin/adminui/style.css`.
- After changing either, regenerate the embedded stylesheet: `go generate ./server/ctrladmin/adminui/`, then rebuild (`07-frontend.md`).
- Never hardcode colours in templates; use the utility classes neighbouring markup already uses.
- Verify each screen you touch against the dark background (`#021a1a`) for readable contrast.

## States

- Every async view needs loading, empty and error states — not just the happy path.
- Empty states say what to do next ("no shares yet", "add a feed above").
- Surface failures as a visible message; never swallow an error silently.
- Live scan status polls `/scan_status`; keep the page stable while it refreshes.

## Interaction

- Destructive actions confirm first: delete user, delete share, eject transcode cache, delete podcast.
- Icon-only buttons get a tooltip and an accessible label.
- Check narrow and wide widths: the layout collapses to one column below the `md:` breakpoint (870px).

## Copy

- Sentence case, imperative.
- Use the fork's vocabulary: "share link", "smart playlist", "scan schedule", "transcode cache".
- README copy describes features for users, never process (`AGENTS.md`).
